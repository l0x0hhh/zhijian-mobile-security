# 智鉴 UI 美术规范

版本 2.0 · 2026-10-18。当前方案：暖白、墨绿的工具型界面；深色模式保留相同信息结构。

本规范替代第一版“深海取证”的排版规则。功能范围、评分与安全要求不变。改版依据见[案例研究与改版](案例研究与改版.md)，Logo 规范见[品牌标识](品牌标识.md)。

## 1. 页面先回答用户的问题

首页回答“选哪个情境、练到哪里”；聊天回答“对方说了什么”；权限回答“应用请求什么、我选了什么”；结果回答“处理对了吗、哪里需要改”。每个页面围绕一个任务组织，标题使用直接名称，不再添加口号。

删除上一版刻意分行的宣言、装饰英文、重复编号、过密的状态胶囊与没有任务作用的波形。不要为每一段文字加圆角卡片，也不要在每条消息下面常驻一组按钮。

| 语义 | 日间 | 夜间 | 用途 |
| --- | --- | --- | --- |
| 页面底色 | `#F6F6F2` | `#171D1B` | 连续的阅读背景 |
| 内容底色 | `#FFFFFF` | `#212925` | 对方消息、文件、必要的分组 |
| 主文字 | `#202923` | `#EEF2ED` | 正文、标题、主要图标 |

| 分隔线 | `#E1E5DE` | `#38443B` | 列表内分组，不作为正文色 |
| 主操作 | `#294D42` | `#A5CAB1` | 主要动作、被选中的导航 |
| 主操作文字 | `#FFFFFF` | `#1B3226` | 主按钮上的文字 |
| 主色浅底 | `#E7EFE8` | `#2C3E32` | 玩家消息与少量图标底板 |
| 风险文字 | `#A24D2A` | `#E9AF85` | 越权或异常，必须附文字 |

| 失败文字 | `#AC343C` | `#F0A9AA` | 已确认的危险处置或失败 |

应用内 Logo 使用独立生成的“对照之窗”，不再用通用指纹图标。图形的陶土角是固定品牌元素，不能随风险状态改色。夜间模式使用暖白小底板承载同一图形；具体留白与文件见品牌标识文档。

普通正文与实际底色的对比度目标至少 4.5:1。当前主要颜色组合已检查；这不等于完整产品无障碍验收。状态同时使用文字或图标，不只依靠颜色。

## 4. 中文排版

使用中文无衬线字体，正文 Regular，标题 Medium。预览使用本机字体，不把系统字体文件打包进入项目。Unity 制作时另选可用的中文字体并登记来源。

| 文字层级 | 逻辑字号 / 行高 | 规则 |
| --- | --- | --- |
| 页面主标题 | 27 至 28 / 38 | 如“安全练习”；不强制写成两行 |
| 结果标题 | 24 至 25 / 36 | 用一句具体结论，不用庆祝口号 |
| 内容标题 | 20 / 30 | 案件名称、检测概况 |
| 顶栏标题 | 17 / 26 | 页面名称或联系人 |
| 正文与权限名称 | 16 / 26 | 核心阅读内容，不缩小以塞入版面 |
| 简述与状态 | 14 / 22 | 一至两行，说明内容本身 |
| 来源、时间、计数 | 12 至 13 / 19 | 不承载重要操作解释 |
| 结果分数 | 42 / 50 | 与“本次得分”对齐，不成为整页中心 |

中文保持默认字距，左对齐；不人为拆开自然句子，不做英文式全大写眉题。两项信息只有存在不同用途时才同时展示，例如线索标题与来源；不要重复用标题、胶囊、描述各说一次同样的话。

页面侧边距 24，小屏为 20；相关信息相隔 8 至 12，段落或分组相隔 24 至 28。列表主要行高约 70，底部操作区为内容预留空间。触控区域至少 44 × 44，主要按钮至少 48 高。

这些是设计逻辑尺寸，不宣称和物理像素、Android dp、Unity Canvas 单位一一相等。现有 1080 × 1920 参考画布继续通过 Canvas Scaler 与安全区域布局适配。

## 5. 列表、容器与按钮

- 连续内容优先使用列表与一条分隔线，不把每一行包成独立卡片。
- 仅在消息、文件或确有边界的内容组上使用白底或抬高底色；容器不叠套。
- 按钮圆角 10、内容组 12、消息气泡 14、底部弹层 22。预览外框仅为展示手机，实际 App 不额外套手机壳。
- 每个操作区有一个主动作；次动作使用中性底或文字。不要把全部按钮都做成长条主色按钮。
- 危险操作使用明确动词和失败语义，不把“危险”当装饰标签。
- 按下、聚焦、禁用、处理中都有独立状态。禁用时以正常对比度解释原因，不靠透明度隐藏缺项。

## 6. 八个页面的排版

### 练习首页

顶栏只保留 Logo、名称与帮助。主标题为“安全练习”，后面直接是三个情境列表。

每个情境包括一个媒介图标、名称、一句话背景、当前进度和入口。继续中的情境显示细进度条，其余显示“尚未开始”。不增加排行榜、成长等级、完成天数等没有需求支撑的指标，不为推荐情境增加宣传海报。

### 调查手机

顶部显示当前案件，紧接一条可打开的新消息。聊天、相册、安全中心、文件管理、设置五个入口共用图标尺寸与标签位置。已收集线索是独立列表入口，不放一张重复计数的大卡片。

### 聊天

一组连续消息只在起点显示头像。文字 16 / 26，对方气泡为内容底，玩家消息为主色浅底。消息按内容决定宽度，不能强制所有气泡等宽。

点选消息后打开操作菜单，里面提供收集线索；长按是补充方式。消息已收集时显示一个小标记。媒体主点击查看或播放媒体，取证不抢占播放动作。底部保留一句操作提示和“分析材料 / 核验身份”两个实际任务入口，不提前在横幅中告诉玩家正确答案。

### 媒体分析

文件信息保持在一行素材区域中，后面用“发现 2 处异常”等直接结论组织内容。每项指标以名称、状态、简短依据组成；不编造置信度，不用重复的胶囊包住每个词。

教学模拟说明清晰可见。“重新分析”是次动作，“加入线索”是主动作。分析进行中提供任务状态；正式媒体尚未制作，样机只展示说明与文字稿。

### 应用信息

应用名、开发者、来源、安装状态集中展示。访问权限和隐私政策各是一个详情入口，不在首屏铺完所有政策段落。

未安装时可先审查；模拟安装后显示“移除模拟应用”。只改变模拟状态，不调用系统安装或卸载接口。危险组合触发终局后，移除不能回滚结果。

### 访问权限

应用名之下，用一行当前风险、一条细条和“已判断 / 总数”表达调查状态。其后为用途选择与七项访问列表。每项显示访问名称与当前值，不在一页常驻七个下拉框。

点击列表项后用底部选择层选择“拒绝 / 允许”；相册区分仅指定照片与全部照片。初始“待判断”是一种明确状态，不把默认关闭等同已拒绝。

案件三可选择拍摄、指定照片或放弃功能。改变用途后按当前权限重新计算风险，不替玩家自动重置选择；历史越权仍记录。其他案件使用各自的用途配置，不能套用证件照的选择。

### 已收集线索

只展示实际已收集条目，包括顺序、简短标题与来源。点开查看原始依据。尚未发现的条目不以四块重复占位出现；只提示缺少的数量，避免泄露答案。

普通提交仍按顶层设计检查必要操作；证据未收齐时提醒并允许在完成操作后按现有证据判断。样机中的结果入口用于查看设计示例，不是完整评分流程。

### 练习结果

顺序为结局、具体原因、得分与能力项、问题、下次做法。标题使用“已通过原号码核实”或“仍然执行了转账”等具体事实。

三项能力采用对齐的文字列表；40 / 40、25 / 30、30 / 30 直接可比较，不再通过三根满分不同的进度条制造额外图形。分数不能覆盖失败：90 分也可以明确显示危险处置失败，正确分项仍保留。

保存状态独立于结局显示。安全通关与最高总分是不同记录，不互相替代。

## 7. 反馈与动效

按钮反馈约 100 至 140 ms，页面切换 180 至 220 ms，底部弹层约 220 ms。取证完成用轻提示，重复收集不重复得分；风险变化立即更新数值，并对条长做短过渡。

不循环扫描光束，不持续闪光，不播放背景音乐或惊吓音。关闭或减少动效时直接展示状态。长正文仍可滚动，但不让整张手机预览出现遮住重要操作的嵌套滚动区。

## 8. Unity 落地与本次检查

保留 uGUI + TextMeshPro、主题资产和公共组件。Theme 统一提供颜色与字号；复用标题栏、列表行、消息气泡、权限选择层、底部操作与反馈。业务图标继续使用同一套线性风格，品牌图形单独导入。

九宫格与布局组承担伸缩，安全区域限制可操作内容；不能把本次总览 PNG 直接贴成整页界面。字体覆盖真实剧情，不通过缩小字号解决溢出。图标、字体与真实媒体在工程阶段落实资源来源。

本次检查了八页深浅配色、320 宽度排版、消息取证去重、分析状态、权限与用途变化，并目视检查新版总览和品牌组合。仅涉及设计文档、预览和图像资源，没有编译 Unity，也没有完成 Android 真机验收。
