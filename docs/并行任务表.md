- 所有窗口先阅读根目录 AGENTS.md，并在编辑前说明预计文件；代码首行添加简略说明，完成后列出实际改动。按刘总要求不自动编译验证。

- 当前窗口是唯一可以修改公共接口、六个 asmdef、AppRoot、场景、预制体、包清单、ProjectSettings、README 与既有设计文档的窗口。其他窗口遇到需要改这些文件的情况，在自己的交付记录中列出建议，等待接入。

- 多窗口不同时启动同一 Unity 工程；当前阶段都不启动编辑器。不要将 Library、Temp、Logs、UserSettings 或构建产物加入 Git。
