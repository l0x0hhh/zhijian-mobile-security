## 已协调的跨窗口差异

1. **同一证据有多个入口**：EvidenceDefinition 保留原 SourceId，新增 SourceIds（主来源加替代入口）与 RequiredSourceIds（必须同时查看的资料）。EvidenceRules 先检查全部前置，再接受任一有效入口，最后仍由同一 evidenceId 去重。语音停顿及三项视频异常支持播放或检测；收款人/非官方下载/照片权限对照保留前置资料。
2. **缺少证据提示**：只返回仍未查看的来源 ID，包含替代与前置来源，不暴露证据标题或结论。已有四条线索仍不是普通提交的硬门槛。
3. **用途前先拒绝**：InvestigationSession 未选用途时允许明确拒绝，允许授权仍返回 permission.select-intent-first。用途本身仍为证件照提交必做项，不默认代选。
4. **会议处置含动作**：用固定 DispositionEffect 三值表示 None/RemoveSimulatedApp/InstallAndGrantSensitive。拒绝并报告先记录处置，再清理模拟安装状态；安装并授予敏感访问在第一次命中组合危险时停止，冻结后不执行余下动作。一次 Application 用例内不发布中间快照，不执行任意脚本或真实安装。
5. **用途 ID**：文稿 `photo-permission.intent.capture` / `.selected-photo` / `.abandon` 映射到 Domain 已规定的 `take-photo` / `selected-photo` / `abandon`。caseId、四证据与核验/分类/处置 ID 保持文稿稳定值。
6. **主背景与段落查看**：消息分别有可阅读来源，音视频与检测仍有独立来源；证件照政策全文、段落和权限单项声明分开，避免把阅读全文等同于取证或同意。
7. **素材台账引用**：AUD-001、VID-001、IMG-VOICE-PAYEE 是待制作条目，不表示已入库。所有实际媒体引用空、许可确认 false；不会因台账字符串非空就开放案件。

沿用而未扩大的规则：会议即时失败为安装＋短信/通讯录任一授权；T3 的 D01 仍保留教师口径解释记录。必要访问被拒绝不等于隐私失败；该项不得满分，用途仍可改选放弃功能。最终结局由领域策略与共同判断条件决定，不从总分或风险为 0 推断安全。
