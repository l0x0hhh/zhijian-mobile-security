## 2. 三关验收路线

| 案件 | 正常路线 | 错误路线 | 应观察的反馈 |
| --- | --- | --- | --- |
| 语音借款 | 查看聊天与语音 → 收集四证据 → 模拟检测 → 审查验证助手并拒绝越权 → 原联系方式核实 → 识别诈骗、拒绝转账并留证 | 从聊天直接选立即转账 | 正常为 Safe；错误为 ScamFailure；有原因与建议 |
| 换脸会议 | 播放视频 → 收集四证据 → 查看三指标 → 审查并拒绝越权 → 通过已知渠道核实 → 拒绝未知安装并留证 | 模拟安装后允许短信或通讯录 | 正常为 Safe；错误为 MalwareFailure；授权风险变化 |
| 证件照权限 | 查看详情与政策 → 收集四证据 → 判断七类访问 → 按需拍摄或指定照片、拒绝其余 → 检查开发者来源 → 识别越权并拒绝应用 | 授予非必要访问后提交，其他必需调查项已完成 | 正常为 Safe；错误为 PrivacyFailure；无聊天 / 检测门槛 |

演示“允许”摄像头或指定照片也只是案例内状态变化，不能触发真实系统访问。每条路线记录关键画面供报告附录使用。

## 3. 重点边界检查

| 场景 | 预期行为 |
| --- | --- |
| 同一证据点击 / 长按十次 | 证据栏只有一条，该证据只加一次分 |
| 收集补充线索 | 可以入栏，但不能突破关键证据总分 40 |
| 重复开始或完成媒体检测 | 返回同一预设结果，不增加额外分数 |
| 扫描中切换关卡或重开 | 旧回调不更新新会话 |
| 未看完必需媒体、未作权限判断或缺少证据就提交 | 列出缺项；即时危险动作仍可触发失败 |
| 案件三未做媒体检测 | 仍可正常完成；不扣不适用步骤的分 |
| 权限反复允许 / 拒绝 | 当前风险按当前状态重算，不累计刷分；首次越权扣分及历史原因保留 |
| 全部拒绝必要访问并放弃使用功能 | 不判为隐私不安全；提示相关模拟功能不可用 |
| 指定照片改为全部相册 | 属于扩大范围，风险上升并产生越权记录 |
| 案件二仅下载、仅安装、仅审查声明 | 不错误触发“安装并敏感授权”组合结局；仍给风险提示 |
| 案件二安装和授权发生顺序变化 | 满足组合条件时始终触发失败；终局不可用撤销操作回滚 |
| 收齐证据后执行危险行为 | 得分不能覆盖危险后果；结果显示失败 |
| 连续点击提交 / 结算 / 保存 | 一个会话只生成一个结果，历史不重复插入 |
| 安全通关后重试失败 | 最高分与安全通关记录不被失败覆盖 |
| 成绩保存后强制结束应用 | 重开仍读到已结算成绩 |
| 未结算时退出调查 | 提示进度未保存；重进为新会话 |
| 主存档损坏 | 尝试有效备份；无可用备份则明确提示，不静默覆盖 |
| 存档版本高于当前程序支持范围 | 保留原文件并显示不兼容信息 |
| 文件写入失败 | 可看结算，明确“未保存”并可重试同一结果 |
| 媒体缺失或播放失败 | 显示错误与重试，不伪造已播放状态 |
| 返回桌面 / 退出案件 / 应用进入后台 | 媒体暂停或停止；返回后状态一致 |
| 断网 | 三关完整可用，没有真实外链或后台请求 |
| 长中文文本、小屏、刘海屏与系统返回键 | 内容可读、底部按钮可达、返回不丢调查状态 |

## 4. 最终现场验收清单

- [ ] 在 Android 设备安装并启动 APK。
- [ ] 完成一个关卡的正确处置，出现安全结局和知识复盘。
- [ ] 重新进入，演示错误转账或错误安装 / 授权，出现风险变化及失败结局。
- [ ] 退出并重新打开，最高分和安全通关状态仍存在。
- [ ] 展示核心规则与案件配置，说明数据、流程和界面如何分工。
- [ ] 展示最终合并的 Android 权限清单，说明素材来源与授权。
- [ ] 三个关卡都可完成，并各具安全与失败结局。
