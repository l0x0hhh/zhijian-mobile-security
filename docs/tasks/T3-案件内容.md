## 3. 内容字段与公开接口边界

未新增或修改 C# 公共接口。文档提供如下内容字段语义，供当前主窗口按现有架构映射；不自行决定代码结构：

| 内容字段 | 接入说明 |
| --- | --- |
| caseId、标题、类型、版本、入口 | 三案稳定 caseId 已确定；contentVersion / scoringRuleVersion 与已注册 policyId 由主窗口分配 |
| roleId、messageId / panelId、正文、类型、动作 | 一二有消息；三只有页面内容，messages 为空；六类消息在一二合计覆盖 |
| mediaId、文字稿/字幕、模拟指标与局限 | 一二有需求和预设教学文案；三为空/不启用；实际 Clip/Video 和 assetLedgerId 未落实，不填造假引用 |
| sourceId、evidenceId、isKey、分值、查看/取证条件 | 各案四关键证据 × 10；不同页面收同一证据仍同一 ID；会议敏感请求为 0 分补充 |
| permissionId、用途、范围、正确答案、分值、风险 | 三案七项分值统一 4/4/4/5/5/4/4 = 30；一二固定用途，三为拍摄/指定照片/放弃功能 |
| 核验、分类、处置 optionId 与反馈 | 是否可靠、是否正确、执行什么动作分开；正确处置不暗中补做核验或替玩家改权限 |
| requiredSteps、即时/最终路径、复盘原因 ID | 三案按适用步骤；不以高分替代安全规则；未完成、错误、不适用分别说明 |

ID 是文档定位键，不表示对应 API、资产或配置已经存在。完整映射、缩写展开与差异记录见[需求映射](../cases/需求映射.md)。
