# S4 动效基础修正

日期：2026-10-19；刘总授权“可以，先处理问题”。本轮只处理动效接入前的两项基础问题及阅读门控，没有添加滑动、淡入、扫描或计分动效。

## 实际修改

### 列表按稳定标识更新

InvestigationRow 新增只读 Key。操作项默认以完整操作意图建立标识，聊天、证据、检测提示、成绩聚合、评分明细和反馈使用稳定 ID 或冻结条目序号；同页重复标识在显示数据构造时拒绝。证据从“加入线索”变为“已收集”仍保留同一 Key，多来源不会重复列出同一证据。

InvestigationPageView 按 Key 保留原行，只有增删项才获取/回收对象，并检查顺序是否实际改变；有界复用池最多保留16行。回收先停用、解除操作上下文，再换父级。InvestigationRowView 的两个按钮只在 Awake 各绑定一次，点击读取最新 DTO；文字、显隐、交互和主题角色分别比较，避免复用后执行旧操作或重复监听。

纯保存状态、按钮可用性等更新不重建整页。确实改变布局时合并至 LateUpdate 处理一次；以可见稳定行的视口位置为锚，尽量保持用户正在阅读的内容，锚点删除时保留当前偏移并限制合法范围。布局等待期间保留新增滚动位移；ScrollDragState 运行时挂在现有 ScrollRect 同一对象，布局恢复后重新设置正在拖动的起点，退出时结束旧拖动。其 Begin/End 接口已与本机 uGUI 源码对照，未执行运行验证。新页才重置到顶部，不对追加行强制滚到底部。主题只处理新行或换色的子树，日夜切换仍保留原全局入口。

### 业务停用与视觉释放分离

IPageHandle 增加 SetPresentationReady 与 Deactivate。PageHandle 在停用时立即阻止输入、解除 Presenter 订阅并取消媒体；Dispose 才停用和销毁画面，两者幂等。Root 只给后续 Unity 视觉适配器借用，资源所有权不转移。

PageRouter 独占页面资源，新增 IPageTransition 视觉驱动接口。成功绑定后先停用旧业务，再调用过渡；完成回调释放旧画面并放开新页输入。快速返回/新导航先失效旧完成回调，再取消并释放上一退场页；同步完成、延迟完成和取消后的旧回调有独立状态。创建/绑定失败清理候选页并恢复仍有效的旧页，停止时取消待完成过渡。当前 AppRoot 显式注入 ImmediatePageTransition，立即完成，没有引入动画延时或第三方包。

### 阅读和图片显示门控

页面在呈现未就绪、布局等待、画面透明或刚刚完成布局时，不发送 SourceRead。逐项登记后才发送事件，回调引起导航/重排时剩余项下帧重新判定，避免提前把未发送项全部标记已读。图片也等待呈现就绪、真实帧末可见及视口覆盖条件，不能只露出边缘或尚在视口外就登记图片消息。音视频取消仍由原 Presenter 立即执行，不等待视觉过渡。
