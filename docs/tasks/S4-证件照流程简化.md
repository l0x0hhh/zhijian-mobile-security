## 本次行为

页面以“查看应用与政策 → 判断权限 → 核实来源 → 整理线索并提交”为主线，显示 1 / 4 至 4 / 4。这是操作指引，仍允许自由回看，不增加正确答案解锁条件。

1. 证件照案首屏从六入口收敛为三个，依次为“开始调查 · 应用详情”“线索夹 · 回看依据”“设置”。相册示例放入相册权限详情；不再把空文件页、安全中心和相册同时摆在首屏。
2. 应用详情直接展示概况、开发者和分发来源；开发者线索在原文旁收集，不再经过“应用详情目录 → 应用详情正文”。
3. 隐私政策按现有全文段落展示一次，包含教学说明和三条款。条款保留独立 sourceId，旁边提供相应线索操作，不必反复进入相似条款页。
4. 三条款实际进入可见区后，页尾阅读进度行才获得全文 sourceId；页尾也实际可见才登记全文。只打开页面或点击下一步不会自动读完全文。
5. 权限页保留三种用途和七项独立判断，显示已判断数量及当前风险。通讯录、短信、后台声明放入对应权限详情。未选用途时提示返回选择用途，仍可阅读声明。
6. 功能与权限不匹配线索在权限页、通讯录 / 短信详情提供入口，继续由既有 EvidenceRules 检查应用功能、两项声明等前置资料，不要求实际授权。
7. 相册权限详情可以看指定照片示例；示例页可直接返回同一相册权限详情。
8. 核验页先提供一个独立来源资料入口，再显示原有核验选项；反馈仍在选择后显示。
9. 线索页显示背景资料、用途、七权限和核验的完成状态，突出“作出判断并提交”。完成标志只表示做过操作，不泄露选择正误。少证据确认和提交缺项继续沿用原有用例。
10. 移除通用资料目录跳向自身的入口；证件照案不再把应用资料叫“会话记录”，也不在原文旁引导到无关安装包。

## 导航边界推演

以下为源码静态推演，均未执行运行验证。

| 路径 / 边界 | 预期行为 |
| --- | --- |
| 当前权限页再次打开当前权限页 | 不新增历史 |
| 权限 → 短信详情 → 返回权限列表 | 回退到已有权限位置；再返回不会重进短信详情 |
| 应用 → 政策 → 权限 → 回看应用资料 | 回到原应用位置，移除其后的导航历史 |
| 相册权限 → 示例 → 返回相册权限 | 回到已有相册权限位置，不追加相同页面 |
| 核验 → 独立资料 → 返回核验 | 回到已有核验位置，不累积重复核验页 |
| 同 Page、不同 ItemId | 不合并不同权限 / 媒体 |
| 同 Page / ItemId、不同 CaseId | 不串案 |
| 首页、调查手机、结果、记录 | 保留原有根导航清栈规则 |
| 快速返回、过渡取消 | 继续使用原有 Navigate / CancelVisualTransition 生命周期 |

路由以 Page、CaseId、ItemId 三项比较。回到旧路由仍创建、绑定当前页面，并从会话读取最新数据；没有缓存旧页面实例，也没有实现跨页面滚动位置恢复。路由变化是公共行为，其他案件的返回路径也需要人工复核。

## 与现实使用的关系

本项目的目标是帮助用户在现实中遇到可疑语音、陌生应用或过度授权时，知道该查什么、如何核实和怎样处置。本轮落实的是围绕一个实际使用目的组织操作，减少功能清单式入口与重复页面。

后续可补充有可靠来源的现实案例改编、许可明确的媒体、贴近真实手机的权限说明，以及复盘里的现实处理步骤；并让首次接触的用户试用，核对其能否独立完成并解释判断依据。以上是后续方向，本轮没有声称已经实现或证明教学效果。

当前音视频检测仍是标注过的预设教学提示。现实媒体鉴定或设备检测能力，需要独立定义数据处理、能力范围和验证标准，不能据本轮页面简化声称已经具备。
