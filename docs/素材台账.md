## 资源入库前记录

每份实际引入素材应补齐：资源 ID、工程相对路径、原始来源 URL 或自制说明、作者、获取日期、许可证名称与许可文件位置、是否允许修改及展示、是否涉及真人肖像或声音、授权证据保存位置、使用案件和处理过程。

如使用生成素材，还需记录生成工具与日期、所用参考素材来源、必要的真人授权和适用使用条件；不能将“AI 生成”当作自动取得一切权限的证明。只用虚构人物的基础版优先。

授权文件如包含个人联系方式或签名，仓库仅记录必要的说明与证明存放位置，原件妥善保存。最终课程报告附录提供适合课堂查验的来源及授权说明。

## 媒体制作约定

- 音频提供文字稿，视频提供字幕；缺失素材用明确占位状态，不伪造检测已经完成。
- 素材大小以真机流畅播放与工程可交付为准，较大文件入库前先确定存储策略。
- 下载链接使用虚构展示文本且由应用内模拟路由处理，不打开外部网站。
- 模拟安装包不包含实际 APK，也不包含真实恶意代码；记录元数据即可。
- 截图与报告不得包含真实短信、通讯录、定位或未授权身份信息。
