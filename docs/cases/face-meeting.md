## 1. 案件定义与边界

## 3. 视频字幕与模拟检测

### 3.1 视频 `face-meeting.media.meeting`

拟制作约 16 秒虚拟人物视频。字幕时间为制作指导，正式媒体完成后须对齐实际时长，本轮未生成视频。片头可见“虚构情境”，播放器另有教学模拟说明；不仿冒真实公司、领导或会议平台。

| 时间 | 字幕 / 台词 | 教学画面需求 |
| --- | --- | --- |
| 00:00–00:04 | 今天临时加个会，用轻会助手参加。 | 虚拟人物开口与声音有轻微、可观察的错位 |
| 00:04–00:08 | 下载链接已经发到聊天里了。 | 转头时面部边缘短暂不稳定，不用惊吓效果 |
| 00:08–00:12 | 装好后打开短信和通讯录。 | 人物脸部与颈部光照方向略有不一致 |
| 00:12–00:16 | 我们马上开始，先把工具准备好。 | 结束画面；不追加新的计分异常 |

上表是待制作的异常示例，不是对已有素材的真实鉴定。实际制作应让三项异常在普通手机尺寸可观察；不能只在检测页写结论而视频中无对应依据。无障碍文字稿保留全部台词，补充画面描述放在可展开的“画面说明”，不在首次播放前泄露关键证据标题。

### 3.2 检测 `face-meeting.detection.meeting`

固定说明：“教学模拟：以下为预设结果，不是真实鉴定。”标题：“发现 3 处异常”；媒体风险：“高（教学预设）”。

| 指标 | 预设状态 | 简短依据 / 对应段落 |
| --- | --- | --- |
| 音画同步 | 异常 | 嘴形与语音有错位。 / 00:00–00:04 |
| 面部边缘 | 异常 | 转头时轮廓不稳定。 / 00:04–00:08 |
| 光照一致性 | 异常 | 脸部与颈部受光不一致。 / 00:08–00:12 |

局限：“这些异常不能单独确认身份，请核对会议来源。”不显示真假概率、置信度、真实机构报告或模型检测声称。扫描完成只更新预设结果，不直接加分；玩家仍需“加入线索”。重新分析不改变结果、不重复奖励。

视频缺失或失败：“视频未能播放，请重试。”检测失败：“分析未完成，请重试。”字幕和静态画面不冒充成功播放，不解锁媒体完成标记。切页、退出或后台时停止或暂停媒体，返回后不自动播放。

资料里应同时给出案例既有渠道供对照，不能只靠 URL 外观认定恶意；“非官方”指本案未在已知工作室渠道发布，不对现实网站作指控。

固定用途：“核对会议来源”。不把未知工具的“同步名单”说法当必要理由，不套用证件照案件的三种用途。七项初始均“待判断”；明确拒绝才算已判断；允许范围只改变案例状态。

## 6. 下载、安装与补救

| 当前模拟状态 | 可见动作 | 结果 / 提示 |
| --- | --- | --- |
| 未下载 | 查看声明；模拟下载 | 查看声明不安装；下载提示“来源未核实，请先核对。” |
| 下载中 | 取消下载 | 停止模拟下载，回到未下载 |
| 已下载 | 删除安装包；模拟安装 | 删除后回到未下载；安装只变为案例内已安装状态 |
| 已安装且未终局 | 移除模拟应用 | 解除安装状态并重新计算危险组合，不擦除历史越权扣分；安全处置同时清理本案模拟安装包 |
| 已移除且未终局 | 查看记录 | 可继续调查；不自动把不可靠核验改为可靠 |
| 已终局 | 查看结果；重试案件 | 不再接受移除或撤销来改写结果；重试为新会话 |

仅点击下载、仅下载成功、仅安装，或在未安装时选择某项访问，都不单独触发本案 MalwareFailure；仍提示风险。预先选择权限属于教学状态，未真实生效。改变安装状态或改变短信/通讯录选择后都重新检查即时规则，不能通过先后顺序绕过。

安全结案时须完成“拒绝未知工具并留证报告”的处置：取消进行中的下载、删除模拟安装包或移除已安装模拟应用。该处置执行后再次检查状态，不能在界面显示已移除而会话仍是已安装。本稿规定行为，不实现清理代码或真实卸载。

### 7.3 处置

| optionId | 手机选项 | 判定 / 行为 |
| --- | --- | --- |
| `face-meeting.disposition.reject-report` | 拒绝未知工具，留证并报告 | 正确；拒绝继续安装，按当前状态取消下载/删除模拟包/移除模拟应用；保留已收集线索并模拟报告，不补齐未收集证据、不替玩家改权限选择 |

| `face-meeting.disposition.keep-installed` | 保留安装，只关闭页面 | 错误；最终提交进入 JudgmentFailure，若已出现敏感授权组合则此前已经即时失败 |

## 8. 普通提交门槛与结局路径

普通提交须满足：基础背景已查看；至少有效收集一条线索；`media.meeting` 成功播放完成；模拟检测完成；七项访问均明确判断；已选择核验并查看反馈；风险分类和处置均已选择。缺项逐条提示“请先播放视频”“还有 {数量} 项访问待判断”等，不要求答案正确。

关键证据少于四条、但已有有效线索且其他必做项完成时，提示“还少 {数量} 条关键线索，可继续查看视频或来源资料。”提供“继续取证 / 按现有证据提交”；不公开未发现的具体答案。扫描/来源页面打开不自动收集证据。

即时规则：**已模拟安装，并且短信或通讯录任一项为允许 → MalwareFailure**。安装和敏感授权每次变化后都检查，两种操作顺序等效；普通提交门槛与高分均不能挡住此结果。当前风险更新和结局在同一操作中冻结，不能靠撤销/移除回滚。

普通提交顺序：先检查上述即时组合；再校验必做项；再处理少证据确认；最后判定结局。可靠核验、分类正确、正确处置、当前七项全拒绝、下载已取消或包已删除/应用已移除 → `Safe`；其他非即时危险结果为 `JudgmentFailure`。没有安装却越权时不会凭空声称发生恶意应用泄露；最终仍未撤销则不算安全。

| 路线 | 操作序列 | 静态预期 |
| --- | --- | --- |
| 完整安全 | 看背景 → 成功播放 → 收四证据 → 检测 → 七项拒绝 → 原联系人或已知工作台核验 → 正确分类 → 拒绝工具、留证报告 → 提交 | Safe，100 分；未下载也可完成 |
| 安装在先 | 模拟安装 → 允许短信 | 立刻 MalwareFailure；不必等通讯录或其他调查项 |
| 授权在先 | 未安装时允许通讯录 → 模拟安装 | 安装动作形成组合时立刻 MalwareFailure |
| 仅安装后补救 | 模拟安装，短信/通讯录均未允许 → 移除模拟应用 → 完成其余安全路线 | 可 Safe；仅安装本身不扣首次越权分 |
| 下载后补救 | 模拟下载 → 删除模拟安装包 → 完成安全路线 | 可 Safe；下载提示不等于已触发恶意应用结局 |
| 高分失败 | 四证据、可靠核验、正确分类、七项曾全拒绝，最终执行安装并敏感授权 | 即时 MalwareFailure；正确分项保留，不能显示安全通关 |
| 普通判断失败 | 四证据、七拒绝、正确分类和正确处置，核验选择“当前聊天” → 提交 | JudgmentFailure，40 + 30 + 20 = 90 |
| 越权后撤销再装 | 未安装时允许短信再拒绝 → 模拟安装（无敏感允许）→ 移除 → 完成安全路线 | Safe，40 + 25 + 30 = 95，当前风险 0；历史错误保留 |

以上未在运行程序执行。课程原文写“安装应用并授权”，本稿按既有设计细化为短信/通讯录任一允许；其他访问如何扩大即时触发范围属于口径待确认项，单列在需求映射，不擅改公共设计。

## 9. 评分与复盘文案

证据四项各 10，共 40。权限 = 最终正确项权重合计 − 首次越权项目数 × 5，最低 0，共 30。安全处置为可靠核验、正确分类、正确处置各 10，共 30；错误与未完成分别显示。检测和安装/移除操作不额外送分，不用总分或风险颜色决定结局。

数值示例：收四证据、可靠核验、正确分类后，安装并允许短信；其余六权限均拒绝。若危险处置为“安装并允许”，证据 40，权限为其余正确项 25 − 首次短信越权 5 = 20，处置为 10 + 10 + 0 = 20，总分 80，结局仍为 MalwareFailure。早期直接安装再允许短信，其余项目未完成时，各正确分项仅按实际状态计算，不套用上述 80 分。
