# 智鉴 P1

入口为 Scenes/Main.scene，由 AppRoot 显式组装纯 C# Presenter 与 uGUI View。PhoneShell 和 Pages 下的预制体可直接在编辑器中调整排版；业务数据通过绑定注入。

本阶段仅实现情境目录、调查入口、帮助、记录空态和会话内主题切换。完整调查、评分、素材播放和存档待后续接入。中文字体在运行时创建动态 TMP 图集；在未运行的预制体编辑视图中，默认拉丁字体可能不能预览中文，不能据此宣称真机显示已验证。

所有 Unity 资产与 .meta 成对保存。此轮未启动编辑器或编译，运行效果仍待刘总打开工程检查。
